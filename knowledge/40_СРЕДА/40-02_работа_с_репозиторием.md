# Работа с репозиторием

Набор — `https://github.com/RungeKut/MCU-Skill`, ветка `main`.
**Порядок, обезличивание, стоп-лист, автор, соавторы, форк и разбор PR —
соседний скилл skill-skill, `knowledge/40_СРЕДА/40-02`; GitHub без `gh` —
там же, 40-03.** Коротко: в начале `git -C <корень> pull --rebase`; после
правки `git diff` глазами → `python tools/check_docs.py --project "<папка
проекта>"` → `git add <файлы>` → `git commit` → **`git push` сразу**.

## Обезличивание: изделие

Кроме общего списка, в набор, текст коммита и PR не попадают:

* название изделия, децимальный номер, номер платы и схемы, имена файлов
  проекта;
* обозначения, имена цепей и компонентов, назначение выводов МК на плате
  изделия;
* протоколы, команды, адреса и форматы обмена изделия;
* номиналы, корпуса и узлы, если по ним узнаётся плата.

**Остаётся**: поведение инструментов и чипов, командные строки, адреса
служебных регистров из руководств, примеры на отвлечённой «плате с
Cortex-M4» или на отладочных платах. Имя чипа можно: это не примета
изделия.

## Стоп-слова набора

* `tools/stoplist.txt` — свой, локальный, вдобавок к общему.
* `--project "<папка>"` или `git config mcu.project "<папка>"` (его
  учитывают и `check_docs.py`, и хук) добавляют к стоп-словам имя папки
  проекта и имена лежащих в ней плат, схем, прошивок и проектов сред
  (`.brd`, `.dsn`, `.sch`, `.pcb`, `.hex`, `.elf`, `.bin`, `.ioc`… —
  `tools/kit_local.py`); сценарии J-Link (`.jlink`) тоже сверяются.
* Описание узла, по которому изделие узнаётся без названия, не ловит
  ничего — за этим `git diff` глазами.
